# Personal Cosmic Book — инструкции для агентов

В проект подключён AI Ops Kit. Перед работой прочитайте `README.md`,
`AI-OPS-ONBOARDING.md` и `.ai-ops/PRODUCT_PASSPORT.md`.

Точка входа: `./ai-ops`. Для понимания проекта — `./ai-ops model`,
для диагностики установки — `./ai-ops doctor`.
Конфигурация находится в `.ai-ops.yaml`; собственный контекст проекта — в `.ai/project/`.
Файлы `.ai/managed/` обновляются установщиком: не редактируйте их вручную.

Правила общения из `CLAUDE.md` применяются ко всем агентам: по-русски,
сначала результат, технические подробности по необходимости; неизвестное обозначайте явно.

Спецификации продукта находятся в `prompts/`, инструкции деплоя — в `DEPLOY.md`.
Сохраняйте десять разделов книги, четыре стихийные темы и разделение расчётов,
генерации текста и оформления, описанное в `README.md`.
Секреты храните в переменных окружения, не добавляйте их в Git.
